Arduino UNO

¿Qué es?

Arduino UNO es una placa con un microcontrolador ATmega328P. Actúa como el cerebro de tus proyectos electrónicos, permitiendo procesar el código que le cargás para controlar otros componentes.

Características

Cuenta con 14 pines de entrada/salida digital, 6 entradas analógicas, una conexión USB para programarlo desde la PC y un conector de alimentación. Es la placa ideal para empezar.

¿Para qué se utiliza?

Se utiliza para crear desde proyectos simples, como encender luces o mover motores, hasta sistemas más complejos como robots, estaciones meteorológicas o domótica casera.
